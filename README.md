# SteamMonkey.games

Static site for SteamMonkey.games.

## Structure

- `index.html` — landing page
- `css/styles.css` — shared site shell and theme
- `js/app.js` — shared navigation behavior
- `assets/images/smonkey-master.png` — approved Smonkey master artwork, copied unchanged

The header/navigation shell is intended to become the common template for future tool pages.

## Deployment

Designed for static hosting on Cloudflare Pages with GitHub integration.
No build step or framework is required.
